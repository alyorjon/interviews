## Kontekst

D01 build dalili root `docs/operations` runbookini 48-o'quv sahifa sifatida katalogga qo'shib yuborganini ko'rsatdi; reja texnik hujjat ham Markdown ekanini hisobga olmagan edi.

## Qaror

Root `docs/` operatsion va arxitektura hujjatlari uchun ajratiladi hamda learning discovery'dan butunlay chiqariladi. Mavjud 47 ta learning sahifa o'z joyida qoladi.

## Nega

Faqat hozirgi runbook nomini maxsus exclude qilish rad etildi, chunki keyingi texnik hujjat yana katalogga sizib kiradi. Sahifa sonini hosil bo'lgandan keyin qo'lda to'g'rilash ham rad etildi: noto'g'ri kontent katalogda qoladi va hisob haqiqatni yashiradi. Operatsion hujjatni learning daraxtiga ko'chirish uning auditoriyasini aralashtiradi.

## Oqibatlar

Root `docs/`ga qo'shilgan yangi Markdown avtomatik ravishda o'quv materiali hisoblanmaydi. Haqiqiy learning sahifani shu daraxtga joylash mumkin emas; katalogga kiritish uchun u learning manbalari joyiga ko'chirilishi kerak.
